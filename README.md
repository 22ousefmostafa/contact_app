## 📱 Features

| Area | Description |
|---|---|
| **Contact List** | View all saved contacts with name and phone number |
| **Add Contact** | Save a new contact with name and phone number |
| **Cloud Storage** | Contacts stored and synced via Firebase Firestore |
| **Quick Access** | Floating action button for adding a contact instantly |

## 🛠️ Tech Stack

| Category | Technology |
|---|---|
| Framework | Flutter |
| Backend | `firebase_core`, `cloud_firestore` |

## Getting Started

```bash
# Clone the repository
git clone https://github.com/22ousefmostafa/contact_app.git
cd contact_app

# Install dependencies
flutter pub get

# Run the app
flutter run
```

> Requires a connected Firebase project (`firebase.json` / `google-services.json` configured).
